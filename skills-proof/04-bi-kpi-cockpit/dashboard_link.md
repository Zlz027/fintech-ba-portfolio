# 看板内容导览与数据更新方式

**当前状态**：看板的数据层已就绪——`data/` 下 4 张 CSV 由 `scripts/build_bi_tables.py` 从 P1-P4 的 outputs 生成，31 项交叉验证全部通过；Tableau Public 发布链接待看板上线后更新（发布步骤见 `README.md`「看板链接」一节）。

## 打开方式

看板上线后：

1. 电脑浏览器直接点链接（推荐 Chrome / Edge）
2. 无需注册、无需登录，打开即看
3. 首次加载需几秒；公司网络受限时可用手机流量打开验证

## 看板内容导览

- 顶部指标卡：CV AUC / 挽留 ROI / 欺诈节省成本 / 融资缺口
- 第二排五图：P1 通过率-坏账率-利润率曲线、P3 成本-阈值曲线（对数轴）、P2 优先挽留散点、P4 13 周现金流（Base 口径）、三情景利润条形图
- 筛选器：风险分层、合同类型（作用于 P2 散点）、情景（作用于三情景条形图）

## 数据更新方式

1. 更新 `data/` 下 CSV，或重跑 `scripts/build_bi_tables.py`（脚本末尾 31 项交叉验证全部通过才会输出 CSV）
2. Tableau Public 桌面版打开工作簿 → `数据 > 刷新所有数据源` → 核对数字
3. `文件 > 保存到 Tableau Public`（**标题不变即覆盖，链接不变**）→ 看板内容更新
