# MVP2 · 星联金科 2026–2028 财务规划一页纸（FP&A 月度经营分析包）

> **数据声明**：本包全部历史与预测数据均为**模拟数据**——"星联金科"为虚构的场景消费金融科技公司（BNPL+助贷），
> 用于完整展示 FP&A 月度经营分析的方法论与可复现工程链路，不构成任何投资建议。

一句话结论：**盈利拐点已确认（2026E EBITDA 2.31 亿、利润率 12.0%），现金是唯一约束——建议 2027Q1 前融资 5.0 亿（股权 3.0 + 授信 2.0），基准情景现金低点由 2.23 亿抬升至 5.23 亿。**

## 4. 方法论摘要

| 模块 | 方法 | 关键参数/口径 |
|---|---|---|
| 收入预测 | Holt-Winters ETS(A,Ad,M)，seasonal_periods=4 | 有界 MLE：α∈[0.4,0.8]、β∈[0.1,0.3]、γ∈[0.1,0.3]；解 α=0.80/β=0.30/γ=0.30；四档边界敏感性 2027E 收入 23.49–24.79 亿 |
| 预测区间 | 80% 区间（蒙特卡洛模拟 1000 次，`random_state=42` 固定） | ETS(A,Ad,M) 无解析区间；固定种子保证可复现 |
| 变现率预测 | Holt 线性趋势 ETS(A,A,N) | α∈[0.2,0.9]、β∈[0.01,0.2] |
| 2028 外推 | 按基准情景 +20% 平移 2027 季节性形态 | 区间宽度按 1.35 倍/年递增 |
| 量价分解 | 规模效应 = ΔV×P25；价格效应 = V26×ΔP | 2026E：+4.40 亿（79%）+ +1.15 亿（21%）= +5.55 亿 |
| EBITDA 归因 | 反事实口径（维持 2025 年利润率） | 规模仅 +0.10 亿、利润率提升 +1.97 亿（95%） |
| 三情景 | 与季度引擎同源：基准 = HW 中枢；悲观/乐观按规模增速 ∓/±12pp、变现率 −0.20/+0.12pp | 2027E 收入 21.19 / 24.72 / 27.97 亿 |
| 变现率敏感度 | 单因素：规模增速固定于基准，take ±0.10/±0.20pp | ΔEBITDA = Δ收入 ×（1−获客%−运营%）；±0.10pp → EBITDA ±0.33 亿，±0.20pp → 3.87–5.18 亿 |
| 现金流引擎 | 期末现金 = 期初 + EBITDA − Capex − ΔNWC；ΔNWC = 6% × 收入环比增量 | 红线 3.0 亿（约 1 季度峰值净流出 + 在途缓冲） |
| 融资路径 | 股权 3.0 亿（2027Q1 一次性）+ 授信 2.0 亿（按需提款，现金 < 4.0 亿时补足；4.5%/年对季初提款余额计息，闲置不计息） | 融资后低点：基准 5.23 / 悲观 0.20 / 乐观 6.51 亿；悲观授信利息合计 0.12 亿 |
| 成本触发 | 悲观预案：连续两季收入增速 <10% 触发，获客 −30% / 运营 −15% | 年化释放 2.46 亿，触发后悲观低点 3.90 亿 |
| 月度粒度 | `MONTHLY` 开关（默认 False），True 时导出 monthly_pl.csv | 季度值三等分均摊；收入/成本可均摊，变现率取季度值、现金取期末余额；不含月度季节性假设 |
| 差异桥 | P&L 行级 EBITDA 贡献口径（成本增加为负），可加和 | 0.24 → 2.31 亿，+2.07 亿 |

## 5. 可复现性与验证

1. **单一事实源**：`outputs/key_metrics.json` 是一页纸数字的唯一来源，HTML 模板程序化注入，无手工转录。
2. **notebook = 脚本**：`P4_analysis.ipynb` 由 `code/p4_analysis.py` + `code/make_charts.py` 组装执行，
   产物与脚本直跑**逐字节一致**（CI 式 diff 校验：`diff outputs/ <notebook重跑产物>`）。
3. **内部一致性 assert**：量价分解加和、差异桥加和、三情景与季度引擎同源、变现率敏感度锚定引擎 2027E 值、融资路径不突破授信额度，均在代码中断言。
4. **确定性**：HW 有界 MLE 点预测完全确定；80% 预测区间为蒙特卡洛模拟估计，已固定 `random_state=42`，
   跨运行/跨环境复现（注意：不固定种子时区间会有约 ±0.2% 的模拟抖动，属正常统计行为）。
5. **路径可移植**：全部脚本通过 `__file__`/cwd 自动定位项目根目录，可从任意位置运行；
   中文字体按"随附提取字体 → 系统字体"顺序注册，跨平台（Linux/macOS/Windows）不出现方框乱码。

## 7. 常见问题（FAQ）

- **Q：数据是真的吗？** 不是——全部为模拟数据，用于方法论演示（见顶部声明）。工程链路与分析方法可直接迁移到真实数据。
- **Q：为什么用 Holt-Winters 而不是 ARIMA/Prophet？** 15 个季度的小样本 + 强季节性，HW 参数少、可解释、可边界约束；ARIMA 在同样本下过拟合，Prophet 需要更长历史。代码内含无约束 MLE 退化对照（弃用）与四档边界敏感性（2027E 收入 23.49–24.79 亿，结论稳健）。
- **Q：授信是一次性到账吗？** 不是——授信 2.0 亿按需提款：仅当季末现金低于 4.0 亿地板价时提款补足，总额不超过额度，按 4.5%/年对季初提款余额计息、闲置不计息。基准情景无需提款、零利息；悲观情景分次提尽、预测期利息合计 0.12 亿。
- **Q：变现率对结论的影响有多大？** 固定规模增速的单因素敏感度：take 每 ±0.10pp，2027E EBITDA ±0.33 亿（ΔEBITDA = Δ收入 ×（1−获客%−运营%），信用与风险分担按放款额计价不受影响）；±0.20pp 覆盖三情景全部变现率离散度，EBITDA 区间 3.87–5.18 亿，不改变融资结论。
- **Q：能出月度口径吗？** 可以——将 `code/p4_analysis.py` 顶部的 `MONTHLY` 置为 `True` 后重跑，会额外导出 `outputs/monthly_pl.csv`（历史+预测 72 个月）。注意这是季度值三等分均摊，模型不含月度季节性假设。
- **Q：一页纸上的数字能改吗？** 不要手改 HTML/PDF——改假设请改 `code/p4_analysis.py` 顶部的显式假设数组，一键重跑全链路。
- **Q：预测区间为什么每次跑一样？** 因为固定了 `random_state=42`（statsmodels 对 ETS(A,Ad,M) 用蒙特卡洛模拟区间）。
