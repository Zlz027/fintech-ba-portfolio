## 1. 背景与问题

星联金科（虚构的场景消费金融科技平台，BNPL+助贷模式）处于从"烧钱换规模"向"单位经济跑通"切换的关键期。管理层（CEO/CFO/董事会）在月度经营会上需要回答四个问题：

1. 2026 年的盈利改善是真实的拐点，还是规模扩张的暂时现象？
2. 增长有多少来自规模、多少来自变现率提升？利润改善靠哪一个？
3. 按当前轨迹，公司什么时候会触及现金红线？需要融多少钱、什么时候融？
4. 如果增长不及预期，公司靠什么预案活下来？

现有信息分散在多个 Excel 与口头汇报中，口径不一、无法追溯，决策会上经常出现"数字打架"。

## 2. 业务目标

| # | 目标 | 衡量标准 |
|---|---|---|
| G1 | 让管理层 **3 分钟内**看懂全年经营全貌与融资决策 | 一页纸 A4：结论先行，不读长文本即可决策 |
| G2 | 让 CFO/董事会 **经得起追问** | 每个数字可追溯到假设与代码；量价分解、三情景、融资建议口径自洽 |
| G3 | 全链路 **可复现** | notebook 一键重跑，产物逐字节一致；数字零手工转录 |
| G4 | 形成可复用的 **月度经营分析模板** | 假设集中显式登记；下月只需更新历史数组 |

## 3. 范围

**范围内（In Scope）**
- 2023Q1–2026Q3 历史季度经营复盘（收入、成本、EBITDA）
- 2026Q4–2028Q4 收入/变现率/EBITDA 预测（Holt-Winters 基准 + 三情景）
- 量价分解与 EBITDA 改善归因（两个口径分别披露）
- 季度级现金流滚动与最低运营现金红线测算（含授信利息计价）
- 融资建议（规模、结构、时点）与悲观情景成本触发预案
- 变现率单因素敏感度（±0.10/±0.20pp）
- 月度粒度切换开关（`MONTHLY`，默认关闭；开启后为季度值三等分均摊，非月度季节性模型）
- 一页纸决策摘要、分析 notebook、演示话术与 QA、速查卡

**范围外（Out of Scope）**
- 税务、法务、审计口径的精确利润表
- 含月度季节性的预测模型（月度导出为均摊口径，仅供汇报颗粒度切换）
- 估值模型（DCF/可比公司）——融资建议仅回答"需要多少钱"，不回答"值多少钱"
- 真实业务数据接入（本版为模拟数据）

## 5. 业务需求（Functional Requirements）

| # | 需求 | 优先级 | 验收对应 |
|---|---|---|---|
| FR-1 | 收入预测采用 Holt-Winters 指数平滑，参数有界 MLE，并披露无约束解的退化对照与边界敏感性 | P0 | AC-1 |
| FR-2 | 量价分解按惯例口径（规模效应=ΔV×P25，价格效应=V26×ΔP）披露；EBITDA 改善归因按反事实口径（维持 2025 年利润率）单独披露，两个口径不得混用 | P0 | AC-2 |
| FR-3 | 三情景与季度现金流引擎同源（基准=HW 中枢，悲观/乐观按规模增速 ∓/±12pp、变现率 −0.20/+0.12pp 缩放），不得出现两套数字 | P0 | AC-3 |
| FR-4 | EBITDA 差异桥为 P&L 行级桥（各行为 EBITDA 贡献口径，成本增加为负），且可加和 | P0 | AC-4 |
| FR-5 | 融资建议明确规模（5.0 亿）、结构（股权 3.0 + 授信 2.0）、时点（2027Q1 前）与提款规则（按需提款、地板价 4.0 亿、按 4.5%/年对季初提款余额计息、闲置不计息） | P0 | AC-5 |
| FR-6 | 悲观情景须有可执行的保护条款（成本触发：连续两季收入增速 <10% 触发，获客 −30%/运营 −15%）并量化触发后现金低点 | P1 | AC-6 |
| FR-7 | 一页纸数字全部由 `key_metrics.json` 程序化注入，禁止手工转录 | P0 | AC-7 |
| FR-8 | 数据声明（模拟数据）在一页纸、notebook、README、BRD 中一致呈现 | P1 | AC-8 |
| FR-9 | 提供变现率单因素敏感度（规模增速固定于基准，take ±0.10/±0.20pp），dt=0 严格锚定引擎 2027E EBITDA（assert 校验） | P1 | AC-10 |
| FR-10 | 提供月度粒度切换开关（`MONTHLY`，默认 False）；开启时导出 monthly_pl.csv，并披露三等分均摊口径 | P2 | AC-11 |

## 6. 口径与假设登记

**口径**：管理会计口径（税前、不含联营）；单位人民币亿元；历史 2023Q1–2026Q3（15 个季度）。

| # | 假设 | 值 | 敏感性/依据 |
|---|---|---|---|
| A1 | 变现率（take rate）路径 | 3.10% → 3.92% | Holt 趋势外推，2027E 中枢 4.13% |
| A2 | 信用成本率 | 1.28% → 1.02% of 放款 | 风险模型改善 + 客群上移 |
| A3 | 获客/运营成本率 | 36%→26% / 28%→21% of 收入 | 规模效应 + 自动化 |
| A4 | ΔNWC | 6% × 收入环比增量 | 行业经验值 |
| A5 | 最低运营现金红线 | 3.0 亿 | 约 1 个季度峰值净现金流出 + 结算在途缓冲 |
| A6 | 2026Q4 Capex | 0.90 亿（递延 0.10 亿非关键开支） | 现金过渡管理 |
| A7 | 融资结构 | 股权 3.0 亿（一次性）+ 授信 2.0 亿（按需提款，地板价 4.0 亿，年利率 4.5%） | 保控制权 + 灵活低成本资金；利息对季初提款余额计价 |
| A8 | 成本触发阈值 | 连续两季收入增速 <10%（2027Q2 末确认，2027Q3 起释放） | 与融资绑定的保护条款；触发后悲观低点 3.90 亿 |
| A9 | HW 参数边界 | α∈[0.4,0.8]、β∈[0.1,0.3]、γ∈[0.1,0.3] | 小样本防过拟合；四档敏感性 2027E 收入 23.49–24.79 亿（中枢 -5%~+0.3%） |
| A10 | 预测区间 | 80%，蒙特卡洛 1000 次，random_state=42 | ETS(A,Ad,M) 无解析区间；固定种子保复现 |
| A11 | 授信利息 | 已计价：4.5%/年（1Y LPR + 适度上浮），对季初提款余额按季计息 | 仅悲观情景提款，预测期合计 0.12 亿；量级远小于触发释放 2.46 亿/年，不影响结论；可按实际报价回填 |
| A12 | 利润配置 | 全额留存（不分红/不再投资） | 乐观情景 2028 年末现金 12.7 亿即源于此；情景度量经营韧性，非资本配置建议 |
| A13 | 月度粒度 | `MONTHLY=False` 默认关闭；开启时季度值三等分均摊 | 模型不含月度季节性假设；月度行仅供汇报颗粒度切换 |

## 7. 验收标准（Acceptance Criteria）

| # | 标准 | 验证方式 |
|---|---|---|
| AC-1 | HW 预测含无约束（退化，弃用）/有界（采用）/窄区间/严区间四档对照，2027E 收入差异 <1.5 亿 | notebook §2 输出 |
| AC-2 | 两个规模贡献口径分别披露且不混用：收入归因 +4.40/+1.15 亿；EBITDA 归因 +0.10/+1.97 亿 | notebook §3 + 一页纸结论第 2 条 |
| AC-3 | 三情景年度 EBITDA 与季度引擎聚合值完全一致（assert 校验） | 代码 assert |
| AC-4 | 差异桥各行加和 = EBITDA 总变化（assert 校验） | 代码 assert |
| AC-5 | 融资路径可解释：股权一次性到账；授信按需提款、不突破额度、按 4.5% 计息；基准/悲观/乐观低点可复算 | notebook §5 + QA |
| AC-6 | 成本触发机制含触发条件、确认时点（2027Q2 末）、释放起算（2027Q3 起）与触发后低点（3.90 亿，守红线） | notebook §5 |
| AC-7 | 一页纸 PDF 严格 1 页；数字与 key_metrics.json 一致（抽查 10 项） | 渲染检查 + 对拍 |
| AC-8 | 模拟数据声明在 4 个交付物中一致出现 | 全文检查 |
| AC-9 | 文档中所有引用数字与 key_metrics.json 一致（含触发后低点、敏感性偏离、退化解 SSE 等派生量） | 全量 grep 对拍 |
| AC-10 | 变现率敏感度 dt=0 复现引擎 2027E EBITDA（assert 校验）；±0.10pp → ±0.33 亿可手算复核 | 代码 assert + 速查卡 |
| AC-11 | `MONTHLY=True` 重跑可生成 monthly_pl.csv（72 行），月度收入加总 = 季度值 | 开关验证 |

## 8. 数据来源与质量

| 项 | 说明 |
|---|---|
| 历史数据 | 15 个季度模拟序列（放款规模、变现率、四项成本率），在 `p4_analysis.py` §0 显式登记 |
| 预测数据 | 由模型生成，无外部数据依赖 |

| 已知限制 | 蒙特卡洛预测区间含模拟误差（±0.2%），已固定种子；月度导出为三等分均摊口径，不含月度季节性 |

## 9. 风险与依赖

| 风险 | 影响 | 缓解 |
|---|---|---|
| 小样本（15 季）导致 HW 参数不稳定 | 预测偏差 | 有界 MLE + 四档敏感性对照 + 区间披露 |
| 悲观情景授信提尽后现金仍探底（0.20 亿，含利息 0.12 亿） | 极端情形失血 | 成本触发条款（触发后 3.90 亿）；融资窗口前置建议 |
| 变现率提升假设不被业务认可 | 收入中枢下修 | 情景表已给出悲观口径（3.93%）；变现率单因素敏感度（±0.20pp → EBITDA 3.87–5.18 亿）；假设集中可改 |
| matplotlib 中文字体环境差异 | 图表乱码 | 随附提取字体 + 系统字体回退链 |
