# BRD：客户流失预测与留存经济性系统（业务需求文档）

**版本**：V1.0（作品集演示版） | **状态**：待业务方评审 | **作者**：经营分析

## 1. 背景与目标

公司获客成本（CAC）持续上升，月流失率约 26.5%（年化口径更高）。目标：

- **业务目标**：将高风险客群的 12 个月留存率提升 5pp；挽留活动 ROI ≥ 1.5；
- **分析目标**：建立可复用的"流失评分 → 价值分层 → 挽留预算分配"流水线，月度刷新。

## 2. 范围

| 项 | In Scope | Out of Scope |
|---|---|---|
| 数据 | 客户宽表（人口属性、服务订阅、账单、合同、在网时长） | 客服通话记录、网络质量 KPI（V2 接入） |
| 模型 | 二分类流失评分（LR/XGBoost）、Cox PH 方向解释、RFM 分群 | 社交网络传播、竞挽（churn-to-competitor）归因 |
| 决策 | 挽留名单、预算分配、合同结构策略 | 定价调整、佣金政策 |

## 3. 干系人

- **业务方**：用户运营部（挽留活动 owner）、市场部（预算）、客服部（名单执行）；
- **数据方**：数据平台（宽表与事件流）、经营分析（模型与度量）；
- **风控合规**：名单触达需过审（不得向敏感客群过度营销）。

## 4. 功能需求

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F-01 | 客户宽表日更（T+1） | P0 | 字段完整率 ≥ 99.5%，`sql/extract.sql` 可在数仓复现 |
| F-02 | 流失评分月度刷新 | P0 | AUC ≥ 0.75，KS ≥ 0.35；cohort AUC ≥ 0.75 |
| F-03 | 风险分层（高/中/低） | P0 | 高风险层捕获 ≥ 60% 实际流失 |
| F-04 | LTV 与 RaR 月度估算 | P1 | 与财务确认口径（毛利率、折现率）后锁定 |
| F-05 | 挽留名单输出（Top-N） | P0 | 含 churn_prob、LTV、expected_save；N 由净利润拐点或预算决定 |
| F-06 | A/B 实验框架 | P1 | 干预组/对照组，校准 uplift 假设（当前 30%） |
| F-07 | 模型监控（PSI、cohort 漂移） | P1 | PSI > 0.25 触发重训评审 |

## 5. 非功能需求

- 全链路可复现：固定种子、版本锁定（requirements.txt）、Notebook 一键执行；
- 数据不落地出域：评分结果仅输出客户 ID 与分数，不回写原始 PII 到分析环境；
- 审计留痕：每次模型训练保留特征快照与指标记录。

## 6. 关键口径定义

| 术语 | 定义 |
|---|---|
| 流失（Churn） | 合同状态由在网转为离网（观察期末快照口径） |
| LTV | horizon=36 个月的折现期望毛利贡献：`Σ MonthlyCharges × 毛利率 × S(tenure+m)/(1+r)^m` |
| RaR | 未来 12 个月期望收入流失：`Σ MonthlyCharges × p × 12` |
| expected_save | 单客户期望保住收益：`p × uplift × LTV` |
| N\* | 累计净利润最大的触达规模（边际收益=边际成本） |

## 7. 风险与依赖

| 风险 | 影响 | 缓解 |
|---|---|---|
| 快照数据无事件时间戳 | 无法严格时序验证 | 生产改用事件流；当前以 tenure cohort 稳定性代理 |
| PH 假设违背 | Cox 风险比为时间平均 | 分类模型为运营口径，Cox 仅方向解释 |
| uplift 假设未校准 | ROI 高估/低估 | 上线 A/B 实验，季度重估 |
| KM 长度偏差 | LTV 系统性偏差 | 与财务对账后引入队列（cohort）留存表替代 |
