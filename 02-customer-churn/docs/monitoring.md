# 监控方案：客户流失预测与留存经济性

> **用途**：回答"模型上线后怎么盯"——监控什么、告警线在哪、越线后做什么。

## 1. 监控对象与频率

| 层级 | 指标 | 频率 | 责任方 |
|---|---|---|---|
| **数据层** | 宽表字段完整率、账单/合同字段缺失 | 日（T+1） | 数据平台 |
| **模型层** | 评分 PSI、各 tenure cohort AUC 漂移 | 月 | 经营分析 |
| **业务层** | 高风险层捕获率、实际流失率 vs 预测、名单触达率 | 月 | 用户运营 |
| **财务层** | 挽留活动实际 ROI vs 假设、uplift 实测值 | 月度（A/B 后） | 经营分析 × 财务 |

## 2. 告警线（三色分级）

| 指标 | 绿（正常） | 黄（关注） | 红（动作） |
|---|---|---|---|
| 评分 PSI | < 0.10 | 0.10-0.25 | **> 0.25** |
| 各 cohort AUC | ≥ 0.75 | 0.70-0.75 | **< 0.70** |
| 高风险层捕获率 | ≥ 60% | 50%-60% | **< 50%** |
| 实际流失率偏离预测 | < 10% | 10%-20% | **> 20%** |
| 挽留 ROI | ≥ 1.5 | 1.0-1.5 | **< 1.0** |

## 3. 越线后的动作（Runbook）

| 触发 | 动作 | 时限 |
|---|---|---|
| 评分 PSI > 0.25 | 定位漂移特征（账单/合同结构变化）→ 评估重训 | 5 个工作日 |
| 某 cohort AUC < 0.70 | 该 cohort 单独重训或单独建模；先暂停该 cohort 的自动名单 | 10 个工作日 |
| 高风险层捕获率 < 50% | 复核阈值配置与分层边界 | 3 个工作日 |
| 实际流失率偏离预测 > 20% | 检查上游事件口径（离网定义是否变更） | 3 个工作日 |
| **挽留 ROI < 1.0** | **暂停大规模触达，回到小规模 A/B**；复算 uplift 与触达成本 | 当日 |

## 4. 重训触发条件（任一满足）

1. 评分 PSI > 0.25；
2. 任一 cohort AUC < 0.70；
3. 实际流失率连续 2 个月偏离预测 > 20%；
4. A/B 实验测得的 uplift 与假设值偏差 > 10pp（会直接改变 N\*）。

## 5. A/B 实验设计（uplift 校准）

> uplift 是本项目最大的不确定性来源，必须用实验校准。

- **分组**：干预组（触达）/ 对照组（不触达），随机分配，样本量保证检出 5pp 留存差异的统计功效 ≥ 80%；
- **度量**：两组留存率之差 = 实测 uplift；与假设值 30% 对比；
- **周期**：至少 1 个完整留存观察窗（建议 ≥ 3 个月）；
- **决策**：实测 uplift 更新 N\* 与预算；若实测 < 10%，项目基本失去经济性，暂停。

## 6. 审计留痕

- **训练快照**：数据集版本、特征清单、超参数、随机种子；
- **口径版本**：毛利率、折现率、horizon、uplift 假设的每次修订留痕；
- **名单留痕**：每次触达名单的生成时间、模型版本、N、预算；
- **PII 保护**：监控与实验数据中的客户 ID 脱敏，原始 PII 不出分析环境。

## 7. 监控数据流

```
数仓（T+1 快照）
   ├─ sql/metrics.sql → 月/日指标表（AUC / PSI / 捕获率 / ROI）
   ├─ cohort AUC 漂移 → 月度报告
   └─ A/B 实验 uplift → 季度校准 → 更新 N* 与预算
        └─ 越线 → Runbook 工单 → 重训/暂停触达
```
