# 监控方案：Fintech 月度经营分析包

> **用途**：回答"经营分析上线后怎么盯"——监控什么、告警线在哪、越线后做什么。

## 1. 监控对象与频率（月度经营节奏）

| 层级 | 指标 | 频率 | 责任方 |
|---|---|---|---|
| **数据层** | 损益宽表完整性、周现金流流水缺失 | 月（T+3 关账后） | 数仓 |
| **经营层** | 预算达成率、价差/量差、CAC、信用损失率 | 月 | FP&A |
| **流动性层** | 周现金余额 vs 缓冲线、回收系数、融资缺口 | **周** | 资金部 |
| **情景层** | 情景乘数假设 vs 实际、预测偏差 | 月 | FP&A × 业务 |

## 2. 告警线（三色分级）

| 指标 | 绿（正常） | 黄（关注） | 红（动作） |
|---|---|---|---|
| 现金余额 vs 缓冲线 | > 缓冲 × 1.2 | 缓冲 × 0.8-1.2 | **< 缓冲线** |
| 回收系数偏离 0.92 | < 1pp | 1-2pp | **> 2pp** |
| 预算达成率 | 95%-105% | 90%-95% / 105%-110% | **< 90% / > 110%** |
| 净收入率环比 | 持平 | −5% 以内 | **−5% 以上**（以价换量失控） |
| 信用损失率环比 | 持平 | +10% 以内 | **+10% 以上**（风险抬头） |

## 3. 越线后的动作（Runbook）

| 触发 | 动作 | 时限 |
|---|---|---|
| **现金余额 < 缓冲线** | 立即启动融资流程；复算 13 周预测与缺口 | 当日 |
| 回收系数偏离 > 2pp | 重跑 13 周预测与融资建议；排查催回政策/客群变化 | 3 个工作日 |
| 预算达成率 < 90% | 拆解价差/量差，定位是量还是价 | 3 个工作日 |
| 净收入率环比 −5% 以上 | 检查定价结构与竞争态势；评估"以价换量"是否值得 | 5 个工作日 |
| 信用损失率环比 +10% 以上 | 联动风控部门排查资产质量；更新损失率假设 | 5 个工作日 |

## 4. 月度滚动重估机制

```
T+3 关账 → 更新月度损益（含预算对比）→ 更新 52 周现金流
   → 重跑 Holt 13 周预测 → 更新现金跑道与融资缺口
   → 三情景乘数回顾（实际 vs 假设）→ 更新前瞻
   → 输出月度经营分析包 → 进资金计划会 / 经营例会
```

- **滚动窗口**：Holt 用最近 52 周滚动重估，α/β 每月重新网格搜索；
- **假设回顾**：回收系数、CAC、损失率、缓冲线逐月回顾，偏离阈值即触发修正；
- **人工修正通道**：已知的结构性变化（新政策、大额支出计划）以人工调整项覆盖模型输出，并留痕。

## 5. 融资决策的监控闭环

| 事项 | 监控内容 | 频率 |
|---|---|---|
| 授信额度 | 已用/未用额度、额度到期日 | 月 |
| 提款计划 | 首笔提取是否按计划（第 4 周前） | 周 |
| 提款后余额 | 提款后现金是否回升至缓冲线上方 | 提款后立即 |
| 缺口变化 | 点预测缺口 vs 压力情形缺口 | 月 |

## 6. 审计留痕

- **预算版本**：每次预算修订保存版本号、修订人、依据；
- **假设版本**：回收系数、CAC、损失率、缓冲线、情景乘数的每次修订留痕；
- **预测快照**：每次 13 周预测保存输入窗口、α/β、点预测与区间；
- **决策留痕**：融资建议的三要素（工具/额度/时点）与最终决策记录。

## 7. 监控数据流

```
数仓（月度损益 + 周度现金流）
   ├─ sql/metrics.sql → 月/周指标表（差异 / 跑道 / 缺口 / 情景）
   ├─ 周度现金监控 → 越线告警（缓冲线 / 回收系数）
   └─ 月度滚动重估 → 更新预测与情景
        └─ 越线 → Runbook 工单 → 融资流程 / 假设修正
```
