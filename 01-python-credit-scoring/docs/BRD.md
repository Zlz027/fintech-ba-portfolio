# BRD：信用风险评分与风险定价联动系统（业务需求文档）

**版本**：V1.0（作品集演示版） | **状态**：待业务方评审 | **作者**：风控 × 经营分析联合

## 1. 背景与目标

消费信贷业务面临两个耦合问题：审批环节缺乏可解释的风险排序（坏账率不可控），定价环节"一刀切"（低风险客户被高价挤出、高风险客户交叉补贴）。目标：

- **风控目标**：评分卡对两年内财务困境的排序力 AUC≥0.78、KS≥0.35（验收线）；
- **经营目标**：风险定价策略相对"无模型统一定价"的全组合年化利润率提升 ≥2pp；
- **合规目标**：每个审批决定可解释（WOE 分值表），利率定价有据（盈亏平衡公式）。

## 2. 范围

| 项 | In Scope | Out of Scope |
|---|---|---|
| 数据 | 申请人征信宽表（额度、逾期、负债、人口属性） | 设备指纹、行为序列（V2 接入） |
| 模型 | WOE 评分卡（LR）+ XGBoost challenger | 深度学习、图模型 |
| 决策 | 通过阈值、风险分档定价、PSI 监控 | 额度优化（limit setting）、催收策略 |

## 3. 干系人

- **业务方**：信贷审批部（阈值与通过率）、定价委员会（利率结构）、财务部（利润口径）；
- **数据方**：征信数据团队（宽表）、模型团队（训练与监控）；
- **合规**：利率上限（24% 红线）、拒贷理由可解释性、公平性（不得受保护属性直接定价）。

## 4. 功能需求

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F-01 | 征信宽表日更（T+1） | P0 | `sql/extract.sql` 可复现；缺失率监控 |
| F-02 | PD 评分月度刷新 | P0 | CV AUC≥0.78、KS≥0.35；PSI<0.25 |
| F-03 | WOE 单调分箱与分值表 | P0 | 每特征 WOE 单调；分值表可人工复核 |
| F-04 | 盈亏平衡利率计算 | P0 | `r*=(PD×LGD+funding+opex)/(1-PD)`，参数由财务部季度校准 |
| F-05 | 通过阈值策略 | P0 | 通过率-坏账率-利润曲线入决策看板 |
| F-06 | 定价建议输出 | P0 | 单客户 rate ≤ 24% 上限；rate ≤ wtp |
| F-07 | PSI 监控告警 | P1 | PSI>0.25 触发重训评审工单 |
| F-08 | A/B 实验（定价结构） | P1 | 低风险客户降价组 vs 对照组，验证份额弹性 |

## 5. 非功能需求

- 可解释：LR 分值表逐箱可解释，拒贷理由可生成；
- 可复现：固定种子、版本锁定、Notebook 一键执行；
- 审计留痕：训练快照、分箱边界、参数版本全部入库。

## 6. 关键口径定义

| 术语 | 定义 |
|---|---|
| PD | 未来两年财务困境概率（模型输出，校准到组合基准率） |
| LGD | 违约损失率（无担保消费贷假设 75%） |
| r* | 盈亏平衡利率 =(PD×LGD+funding+opex)/(1-PD) |
| wtp | 客户愿付利率 = r* + 竞争溢价（假设 3pp） |
| 全组合利润率 | Σ 批准客户预期年损益 / Σ 全部申请人 EAD（被拒者计 0） |
| S0/S1/S2 | 无模型 / 仅评分筛选 / 评分+风险定价 三策略 |

## 7. 风险与依赖

| 风险 | 影响 | 缓解 |
|---|---|---|
| 数据为 2011 静态样本 | 无严格 OOT，概念漂移风险 | 上线后按月 PSI + realized default 回测 |
| LGD/愿付为假设值 | 利润增量高估/低估 | 财务部季度校准；A/B 实验验证份额弹性 |
| 单调分箱牺牲 U 型信号 | age 等特征失效 | LR+XGBoost 双轨；生产可对 age 做分位哑变量 |
| 利率上限 24% 约束 | 高 PD 尾部不可定价 | 阈值拦截 + 补充担保产品分流 |
