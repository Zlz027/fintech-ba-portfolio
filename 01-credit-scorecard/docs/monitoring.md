# 监控方案：信用风险评分卡 × 风险-定价联动

> **用途**：回答"模型上线后怎么盯"——监控什么、告警线在哪、越线后做什么。

## 1. 监控对象与频率

| 层级 | 指标 | 频率 | 责任方 |
|---|---|---|---|
| **数据层** | 关键特征缺失率、取值域异常 | 日（T+1） | 数据团队 |
| **模型层** | 特征 PSI、评分 PSI | 月 | 模型团队 |
| **业务层** | 分档实际坏账率 vs 预测 PD、通过率、成交率 | 月 | 风控策略 |
| **财务层** | 全组合利润率、定价偏离度（实际利率 vs r\*） | 月 | 财务/经营分析 |

## 2. 告警线（三色分级）

| 指标 | 绿（正常） | 黄（关注） | 红（动作） |
|---|---|---|---|
| 特征 PSI | < 0.10 | 0.10-0.25 | **> 0.25** |
| 评分 PSI | < 0.10 | 0.10-0.25 | **> 0.25** |
| 分档坏账率偏离预测 | < 10% | 10%-20% | **> 20%** |
| 通过率变动 | < 5pp | 5-10pp | **> 10pp** |
| 定价偏离（实际<r\*） | 0 笔 | — | **> 0 笔**（即出现亏损定价） |

## 3. 越线后的动作（Runbook）

| 触发 | 动作 | 时限 |
|---|---|---|
| 特征 PSI > 0.25 | 定位漂移特征 → 检查上游数据管道 → 评估是否重训 | 5 个工作日 |
| 评分 PSI > 0.25 | 启动重训评审工单；对比新旧模型在留出集的表现 | 10 个工作日 |
| 坏账率偏离预测 > 20% | **立即暂停高 PD 段的自动审批**，人工复核；复算 LGD 与实际回收 | 1 个工作日 |
| 出现定价 < r\* | 检查定价引擎参数版本；紧急回滚至上一版本 | 当日 |
| 通过率变动 > 10pp | 复核阈值配置与客群结构，排除配置错误 | 3 个工作日 |

## 4. 重训触发条件（任一满足）

1. 评分 PSI > 0.25；
2. 分档坏账率连续 2 个月偏离预测 > 20%；
3. 累计新增坏样本 ≥ 500 条（保证重训样本量充分）；
4. 业务政策变更（如利率上限调整、新增产品线）。

## 5. 审计留痕（合规要求）

- **训练快照**：每次训练保存数据集版本、特征清单、超参数、随机种子；
- **分箱边界**：WOE 分箱边界随模型版本入库，保证历史评分可复算；
- **参数版本**：LGD / funding / opex / 愿付溢价假设的每次修订留痕（谁、何时、依据）；
- **决策可追溯**：单笔审批的评分、阈值、建议利率、拒贷理由全部落库，保存 ≥ 5 年。

## 6. 监控数据流

```
数仓（T+1 快照）
   ├─ sql/metrics.sql → 日/月指标表
   ├─ PSI 计算（基准=训练集分布）→ 月度报告
   └─ 分档坏账率回测（realized vs predicted）→ 月度报告
        └─ 越线 → Runbook 工单 → 重训/回滚
```
