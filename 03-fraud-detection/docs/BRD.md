# BRD：交易欺诈检测与成本敏感拦截系统（业务需求文档）

**版本**：V1.0（作品集演示版） | **状态**：待业务方评审 | **作者**：反欺诈 × 经营分析联合

## 1. 背景与目标

信用卡欺诈率仅 0.13%-0.17%，**单纯追求 AUC/召回没有经营意义**：每一笔误杀有真实成本（人工审核 + 客户体验），每一笔漏判有真实损失（欺诈金额 + 调查成本）。目标：

- **识别目标**：AUPRC≥0.60（不平衡场景主指标）、AUC≥0.95；无监督基线（Isolation Forest）仅作兜底对照；
- **经营目标**：相对"不拦截"基线，总成本（误杀 + 漏判）下降 ≥50%；相对"全量人工审核"下降 ≥90%；
- **合规目标**：拦截决策可解释（SHAP + 规则引擎双通道），阈值标定过程留痕可审计。

## 2. 范围

| 项 | In Scope | Out of Scope |
|---|---|---|
| 数据 | 授权交易流水 + PCA 脱敏特征（V1-V28） | 原始设备指纹/行为序列（V2 接入） |
| 模型 | XGBoost（class_weight）+ Isolation Forest 基线 | 深度学习、图神经网络 |
| 决策 | 成本最优阈值、规则前置拦截、复核队列 | 拒付追偿、司法流程 |
| 监控 | PSI/精确率/Top-K/每千笔成本 四指标 | 全链路 MLOps 平台 |

## 3. 干系人

- **业务方**：反欺诈运营部（拦截名单处置）、客服部（误杀客诉）、财务部（成本矩阵校准）；
- **数据方**：交易特征平台（V1-V28 每日重算）、模型团队（训练与监控）；
- **合规**：拦截理由可解释、客户告知义务、公平性审计（不得因客群属性系统性误杀）。

## 5. 非功能需求

- 可解释：SHAP 全局因子 + 规则引擎前置拦截双通道；
- 可复现：固定种子、版本锁定、Notebook 一键执行；
- 低延迟：评分推理 P99 < 50ms（生产要求，演示版不测）。

## 6. 关键口径定义

| 术语 | 定义 |
|---|---|
| 类别不平衡三法 | class_weight（scale_pos_weight）/ SMOTE 过采样 / 随机欠采样 |
| AUPRC | 精确率-召回率曲线下面积；不平衡场景主指标（基准线=欺诈率） |
| 时序切分 | 按 Time 字段前 80% 训练、后 20% 测试；随机切分会因欺诈批次集中而泄漏虚高 |
| 误杀（FP） | 好交易被拦截，成本 = fp_cost（假设 ¥120 = 审核 ¥30 + 体验 ¥90；¥30 = 客服复核 5 分钟 × ¥6/分钟，¥90 = 误杀致流失概率 +1% × LTV ¥9,000，LTV = 年消费 ¥15 万 × 商户费率 0.6% × 留存 10 年） |
| 漏判（FN） | 欺诈放行，成本 = 欺诈金额全额 + miss_fixed（假设 ¥50） |
| 成本最优阈值 | argmin 总成本；总成本关于阈值分段常数，按概率降序精确求解 |
| 监控四指标 | 评分 PSI、阈值精确率、Top-500 精确率、每千笔期望成本 |

## 7. 风险与依赖

| 风险 | 影响 | 缓解 |
|---|---|---|
| 欺诈手段演化（概念漂移） | 模型衰减，PSI 越线 | 日级 PSI 监控 + 触发重训工单 |
| 误杀客诉 | 客户流失、品牌损失 | 阈值敏感性分析 + 复核队列 + 客诉回流校准 fp_cost |
| 成本矩阵假设失真 | 阈值偏离最优 | 季度校准 + A/B 实验 + 人工抽检 5% |
| 规则引擎过拟合 | 前置规则漏掉新形态 | 规则按月评估召回衰减，与模型分双通道互补 |

## 8. 验收结论（演示版实测）

- 三法对比：class_weight AUC 0.9891 / AUPRC 0.7993（冠军，训练成本最低）；
- 时序切分 vs 随机切分：AUPRC 0.7993 vs 0.8764——随机切分虚高 9.6%，评估必须用时序切分；
- 成本最优阈值 0.5388：拦截 0.11% 交易、召回 74.7%、精确率 90.3%，总成本 ¥4,309 vs 不拦截 ¥11,479（-62.5%）、全量人工审核 ¥1,711,952（-99.7%）；
- 规则提取：V14/V4/V12 组合规则覆盖 236 笔、精确率 23.3%（基准 177 倍）、召回 73.3%。
